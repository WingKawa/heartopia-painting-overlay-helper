# 色盤量測資料

本目錄包含 Heartopia 遊戲色盤的 13 張 PNG 截圖，以及重建 125 色資料所需的取樣座標、檔案雜湊與量測報告。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `group_01.png`～`group_13.png` | 第 1～13 組主色展開後的色盤截圖。 |
| `manifest.json` | 截圖尺寸、SHA256、組別及每個子色的取樣範圍。 |
| `measurement.json` | 各色 RGB、取樣像素數、最小值與最大值，以及 manifest 的 SHA256。 |

色號依遊戲的兩欄排列，由左至右、由上至下計數。第 1 組有 5 色，其餘每組各 10 色。透明圖示不屬於 125 色。

## 量測方法

每個色塊選取內部 21×21 像素，避開選取白框、邊緣高光與陰影。取樣範圍使用左上包含、右下不包含的 `[x0, y0, x1, y1]` 像素座標。

腳本直接讀取 PNG 的 RGB 通道，不縮放、不套用 ICC 或 gamma 轉換、不做色彩量化。每個範圍內的 441 個像素必須完全同色且不透明，否則停止量測。完整結果必須包含 125 個彼此不同的顏色。

## 重建色盤

在專案根目錄執行，指定尚不存在的輸出路徑：

```powershell
.\venv\Scripts\python.exe scripts/measure_palette.py --output build/palette-rebuilt.json --report build/palette-rebuilt-report.json
```

腳本不會覆蓋 `data/palette.json`。測試會重新讀取截圖，確認量測輸出與程式使用的色盤及報告一致。

## 更新資料

更換截圖後需更新 manifest 的尺寸、雜湊與取樣範圍，重新產生量測報告及色盤，再執行測試。色號及 index 會影響圖片與工作階段中的顏色對應，更新時應保留其排列規則。

截圖是色盤區域的裁切圖，不能用於完整遊戲視窗的座標校正。量測結果代表 PNG 中色盤 UI 的顏色，不代表遊戲內部色彩參數或畫布上的渲染色。

使用前先看

從對齊到填色，一步步畫出作品

載入圖片、設定畫布並校正格子大小後，就可以按照下面的方式開始繪畫。先看實際畫面，再從步驟 1完成設定；所有圖片都可點開放大。

1. 利用畫布邊界對齊，例如左上角

先把遊戲畫布拖到看得見左上角的位置，再顯示疊層、按 F9 切到「對齊模式」。用左鍵拖曳疊層，讓疊層左上角的第一格與遊戲畫布左上角的第一格重合，同時確認附近格子也對齊。

這兩張圖中的「1,1」等數字是格子的列、欄位置，與取色後顯示的遊戲色號不同。詳細操作見步驟 4：對齊疊層。

2. 切到繪畫模式，移到想畫的區域

對齊後按 F9 切到「繪畫模式」，並勾選繪畫輔助中的右鍵拖曳同步功能。在遊戲畫布內按住右鍵拖曳，疊層便會跟著畫布移動，讓要畫的部分出現在眼前。

拖曳後先確認是否仍對齊。若有些許偏差，保持「方向鍵微調疊層」勾選，點回遊戲後可用 ↑ ↓ ← → 微調；Shift＋方向鍵可加快移動。偏差較大時，按 F9 回到對齊模式重新拖曳對齊。

3. 取出一種顏色，只看這次要填的格子

按 F5 開啟取色模式，再點疊層上一個有色格子。疊層會只顯示同一種顏色，並以中心亮點與邊框提示位置；工具介面會顯示對應的遊戲色號。

在遊戲色盤選好對應顏色後，手動填入這些格子。色號讀法與選色操作見步驟 5：取色與繪畫。

4. 一次完成一種顏色，再繼續下一種

這一區填好後，按 F6 顯示全部顏色，再按 F5 取下一種顏色，繼續填色。需要換區域時，右鍵拖曳畫布並確認對齊，重複「取色 → 選色 → 填色」，逐步完成整張圖。

疊層提示不會因為遊戲中已填色而自動消失；可按 F8 暫時隱藏疊層，查看實際完成的部分。

開始設定：載入圖片 →

步驟 1

從右上方「載入圖片」開始

  1. 開啟工具，按右上方 ① 載入圖片，選擇要畫的圖片。
  2. 也可按 ② 轉為小鎮125色… 開啟轉圖視窗，將圖片轉為小鎮支援的色彩。轉圖操作見補充說明：轉圖、微調與儲存。
  3. 載入完成後，左側小地圖會顯示作品；右側三個頁籤用來設定作品、疊層與繪畫工具。

圖片中的一個像素，對應疊層的一格。

步驟 2

先設定作品，再決定觀看哪一區

  1. 選擇右側 ① 作品設定，選擇常用尺寸，或輸入畫布寬、高，再按「套用畫布大小」。單位為格。
  2. 決定圖片要放在哪裡：選擇左側 ② 調整圖片位置，再在小地圖上拖曳圖片。例如將圖片放在畫布中央，或移到右下角；這會改變作品的構圖。也可按「圖片置中」或「重設圖片位置」。
  3. 決定現在要畫哪一區：選擇 ③ 移動觀看範圍，拖曳小地圖上的青色框，選擇疊層要顯示的部分。例如先畫左上角，再把青色框移到右下角。這不會改變圖片在作品中的位置。
直接移到指定格子

在小地圖下方輸入列、欄，再按「移至此格」，即可將青色觀看框的左上角移到該格。

步驟 3

連接遊戲，讓疊層格子大小一致

  1. 開啟遊戲的繪畫介面。在工具按上方 ① 連接遊戲視窗，再用滑鼠點一下遊戲視窗，完成連接。Esc 可取消等待。
  2. 在遊戲中打開畫布，調整放大倍率，直到格線清楚可見。工具需要先取得遊戲視窗的尺寸，再量測畫面中的格子大小，才能讓疊層與遊戲格子相配。
  3. 先隱藏疊層，點回遊戲視窗，按 Alt＋PrintScreen 複製完整遊戲截圖，不要裁切。
  4. 回到工具，開啟 ② 疊層設定，按 ③ 貼上截圖並校正格子寬高與格距…，再按「貼上截圖」或 Ctrl＋V。
  5. 在預覽上框選畫布內部，每個方向至少包含四條完整格線。按「量測格線」，確認結果後按「套用量測結果」。
也可以手動調整格子大小與間距

在「疊層設定」以滑桿調整格子寬高，或輸入格子寬高與格距，再按「套用尺寸」。格距是格子之間的留白。

校正完成後，還需要在下一步拖曳疊層，對齊遊戲格子。

步驟 4

在對齊模式，拖曳疊層重合格線

  1. 顯示疊層，按上方 ① 模式按鈕 或 F9，切到「對齊模式」。
  2. 在遊戲畫布上，按住左鍵拖曳疊層，讓色塊與遊戲格子重合。建議利用畫布左上角等邊界作為對齊基準，先讓兩邊的第一格重合，再確認附近格子。可先看實際對齊與繪畫範例；下圖示意格線與疊層的位置關係。
  3. 對齊後，再按模式按鈕或 F9 切到「繪畫模式」。此時滑鼠可直接操作遊戲。
步驟 5

取出一種顏色，再到遊戲填色

想先看取色後與畫到一半的實際畫面，可閱讀實際繪畫流程。

  1. 確認已切到「繪畫模式」。按 F5 或「繪畫工具」中的 ① 從疊層取色，再點疊層上的有色格子。
  2. 取色後，疊層與小地圖只顯示同色格子，工具會顯示對應色號。按「顯示全部顏色」或 F6 恢復完整圖片。色號的數法見下方圖解。
  3. 在遊戲中展開右側色盤，可依色號自行選色。自動選色預設關閉；若要使用，請先閱讀官方規章與資料使用說明，在工具勾選「啟用自動選色（會操作滑鼠）」，首次啟用時選擇「了解風險並啟用」。之後按 ② 自動切換畫筆顏色 或 F7，再點回遊戲視窗。
  4. F7 會執行選色腳本，移動並點擊滑鼠。請保持遊戲在最前方，暫停操作滑鼠，等待選色完成，再繼續填色。執行中可按 Esc 取消。
  5. 若要移動畫布，在 ③ 繪畫輔助 中勾選「右鍵拖畫布，同步移動疊層」，再從遊戲繪畫區按住右鍵拖曳。
  6. 拖曳後疊層與遊戲畫布可能偏移，請自行確認。勾選「方向鍵微調疊層」後，可用方向鍵快速修正，搭配 Shift 可加快移動；也可按 F9 切回對齊模式，用左鍵拖曳重新對齊。
另一種取色方式：Shift＋左鍵

在繪畫模式，按住 Shift 再用左鍵點疊層的有色格子，也可直接取色，不必先按 F5。

色號怎麼數？以 7-3 為例

先展開遊戲色盤，再使用 F7

點擊遊戲右側的調色盤按鈕，展開選色條，讓上方彩色長條及下方各個色塊都出現，再執行自動選色。

校正 F7 自動選色的位置

F7 沒有反應或選錯顏色時，可重新校正色盤位置。

  1. 先在遊戲中展開色盤，確保上方選色條與下方所有色塊都清楚可見，沒有被其他視窗遮住。
  2. 點回遊戲視窗，按 Alt＋PrintScreen，複製完整遊戲截圖，不要只裁切色盤。
  3. 回到工具，在「繪畫工具」展開「色盤位置與校正」，按「貼上截圖並校正色盤位置…」，再貼上截圖。
  4. 在貼上的預覽中，框選色盤上方的選色條與下方全部色塊，按「辨識色盤」。
  5. 確認編號點對準各個色塊，按「保存色盤校正」，再使用 F7 選色。
補充說明 · 載入圖片

微調轉色結果，另存成 PNG

需要轉圖時，從步驟1開啟此處操作；完成後可返回載入圖片，繼續設定作品。

  1. 在轉圖視窗上方 ① 選擇常用尺寸，或輸入像素寬、高，再選擇縮放方式。若要保留原圖的一部分，可勾選「手動裁切」，在原圖上調整裁切框。
  2. 使用 ② 色彩微調 的滑桿調整，右側會自動更新預覽。白位往右讓亮部更白；黑位往右讓暗部更黑。按「恢復色彩預設」可取消這些色彩調整。
  3. 預覽完成後，按下方 ③ 另存圖片… 儲存 PNG；或按 ④ 使用轉換結果 載入主視窗。

也可從主視窗另存完整作品

主視窗右上方的「另存圖片…」會儲存目前作品畫布中的全部顏色，保留調整後的圖片位置。即使正在只顯示某一色，或只觀看圖片的一部分，仍會儲存整張作品。

補充說明 · 問題處理

出現問題時，匯出診斷紀錄

這一頁供遇到問題時查閱，不是完成繪畫的必做步驟。

  1. 遇到問題後，先記下剛才的操作與大約發生時間。
  2. 按主視窗右上方「功能檢查」。
  3. 按下方 ① 匯出診斷紀錄…，儲存 ZIP，將這份檔案連同問題描述交給開發者。

紀錄不會自動傳送，需自行匯出後提供；匯出的檔案不包含作品或截圖。

快捷鍵、連線與視窗的常見情況
  • 若快捷鍵、同步拖曳或自動選色沒有反應，可在「功能檢查」查看遊戲是否以系統管理員身分執行。若是，請關閉工具，再對工具的執行檔按右鍵，選「以系統管理員身分執行」。
  • 部分鍵盤需要搭配 Fn 才能使用 F5～F9。也可直接按工具上的對應按鈕。
  • 找不到遊戲時，按「連接遊戲視窗」，再切回遊戲。
  • 主視窗可被其他視窗蓋住；只有疊層保持置頂。

官方規章與資料使用

工具用途與運作方式

本工具提供圖片轉色、疊層參考、取色與位置調整，供玩家手動繪畫使用。同步移動功能會依玩家的滑鼠操作調整疊層位置，不會代替玩家拖曳遊戲畫布。

「自動選色」是可選的自動化功能，預設關閉。啟用後，每次由玩家按下按鈕或 F7，工具會等待玩家切回遊戲，再執行滑鼠移動與點擊，切換畫筆顏色。執行期間請暫停操作滑鼠，等待完成；可按 Esc 取消。不啟用也可使用疊層與取色功能，並自行在遊戲內選色。

在「繪畫工具」勾選「啟用自動選色（會操作滑鼠）」，首次啟用會顯示操作與風險說明。確認後才會啟用；之後會記住你的選擇。取消勾選會停止等待或執行中的選色，F7 也不會再啟動腳本。

官方規章與使用風險

本工具為非官方第三方工具，未取得遊戲營運方的使用許可或背書。本工具無法保證使用後不會收到警告、功能限制或帳號停權等處置。請自行評估是否使用，並承擔相關風險。

是否允許使用本工具及其各項功能，應以玩家所使用版本適用的最新官方協議、公告及營運方判定為準。

關閉自動選色，只會停用該項滑鼠自動操作，不代表其他輔助功能已獲官方允許。用途為繪畫輔助、不讀取遊戲記憶體，或由玩家在場操作，也不等於符合官方規章。

工具會使用哪些資料？

  • 本工具不讀取或修改遊戲程序記憶體、遊戲存檔，也不存取遊戲帳號系統或取得登入憑證。
  • 會讀取遊戲視窗的位置與尺寸等資訊，並觀察相關鍵盤、滑鼠操作，用來連接視窗、取色及同步疊層；「功能檢查」也會查詢程序的執行權限。
  • 校正功能使用玩家貼上的截圖；自動選色會暫時擷取遊戲畫面，以辨識色盤位置與顏色。校正及自動選色使用的截圖不會自動儲存或上傳。
  • 作品快照、操作設定及診斷紀錄保存在本機。診斷紀錄不包含截圖或一般打字內容，但可能包含檔名、視窗標題及操作狀態，由玩家自行決定是否匯出提供。

本工具不會自動上傳圖片、截圖、設定或診斷紀錄。點選官方協議連結時，會使用瀏覽器造訪官方網站。

Heartopia 繪畫疊層小幫手 — 0.1.1

適用系統：Windows 10／11，64 位元（x64）。
請將 ZIP 完整解壓縮，並保留整個資料夾。

啟動
1. 雙擊 HeartopiaPaintingOverlayHelper.exe 開啟工具。
2. 首次啟動會開啟圖文教學；也可隨時按「使用教學」重開。
3. 開啟遊戲的繪畫介面，在工具按「載入圖片」。
4. 按「連接遊戲視窗」，再用滑鼠點一下遊戲視窗，完成連接。Esc 可取消等待。

準備圖片
圖片中的一個像素，對應疊層的一格，可使用任意長寬。
使用小鎮125色的 PNG 可直接載入；需要轉色的圖片會開啟轉圖視窗。
也可按「轉為小鎮125色…」，將圖片轉為遊戲可用的顏色。
選擇常用尺寸，或輸入像素寬高，再選擇完整保留、裁切填滿或拉伸。
若要保留原圖的一部分，勾選「手動裁切」，拖曳裁切框移動，或拉動四角調整範圍。
按「使用轉換結果」將圖片載入主視窗。

色彩微調與另存圖片
1. 在轉圖視窗拖曳色溫、亮度、對比、飽和度、白位或黑位滑桿，右側預覽會自動更新。
2. 色溫往左偏冷、往右偏暖；白位往右讓亮部更白，黑位往右讓暗部更黑。
3. 按「恢復色彩預設」可取消色彩調整，保留目前尺寸與裁切範圍。
4. 按「另存圖片…」可將轉圖結果存為 PNG；按「使用轉換結果」則會載入主視窗。
5. 主視窗的「另存圖片…」會儲存作品畫布中的全部顏色，保留調整後的圖片位置。即使只顯示某一色或只觀看圖片的一部分，仍會儲存整張作品。

繪畫
1. 先連接遊戲視窗，再調整遊戲畫布放大倍率，讓格線可見。依下方「截圖校正格線」量測格子大小與間距。
2. 在工具切到「對齊模式」，以左鍵拖曳疊層，對齊遊戲格子。
3. 按 F9 或上方模式按鈕切到「繪畫模式」，在遊戲中對照疊層填色。
4. F8 可顯示／隱藏疊層；F9 可切回對齊模式重新調整。
5. 勾選「右鍵拖畫布，同步移動疊層」後，從遊戲繪畫區按住右鍵拖曳，可讓疊層跟著移動。
   拖曳後疊層與遊戲畫布可能偏移，請自行確認；有偏移時按 F9 切回對齊模式重新對齊。
6. 勾選「方向鍵微調疊層」後，在遊戲中按方向鍵可微調位置；搭配 Shift 可加快移動。
7. 拖曳中斷後，請放開右鍵，再重新按住拖曳。

畫布與小地圖
1. 「作品設定」的畫布寬、高決定作品範圍，單位為格。可選常用尺寸或自行輸入，再按「套用畫布大小」。
2. 要決定圖片在作品中放在哪裡，選「調整圖片位置」，在小地圖拖曳圖片；也可按「圖片置中」或「重設圖片位置」。
3. 要選擇目前要畫哪一區，選「移動觀看範圍」，拖曳小地圖上的青色框。這不會改變作品構圖；遊戲畫布需自行拖到對應位置。
4. 也可輸入列、欄後按「移至此格」，將觀看框的左上角移到指定格子。
5. 超出作品畫布的圖片部分不會顯示在疊層上；沒有圖片的區域，在小地圖以棋盤格表示。

取色與逐色顯示
1. 在繪畫模式按 F5 或「從疊層取色」，再點疊層的有色格子。也可按住 Shift＋左鍵直接取色。
2. 取色後，疊層與小地圖只顯示同色格子，並以邊框與中心點標示。
3. 工具會顯示色號，例如「7-3」代表第7組第3個顏色。
4. 組內顏色由左至右、由上至下計數：第一列1、2，第二列3、4，以此類推。
5. 按「顯示全部顏色」或 F6，可恢復完整圖片。

自動切換畫筆顏色
1. 先在遊戲展開右側色盤。
2. 此功能預設關閉。請先閱讀「官方規章與資料使用說明」，在「繪畫工具」勾選「啟用自動選色（會操作滑鼠）」，首次選擇「了解風險並啟用」。取色後按「自動切換畫筆顏色」或 F7，再切回遊戲。
3. 切回遊戲並放開滑鼠與鍵盤按鍵後，工具會執行選色腳本，移動並點擊滑鼠。請保持遊戲在最前方，暫停操作滑鼠，等待選色完成再繼續繪畫。
4. 按 Esc 可取消；也可在工具按「取消等待切換」。
5. 若沒有反應或選錯顏色，可使用下方的「截圖校正色盤」。
6. 取消勾選「啟用自動選色」會停止等待或執行中的選色；關閉時，按鈕與 F7 都不會執行腳本。你的啟用選擇會保存。

介面與主題
1. 左側為作品小地圖，右側分為「作品設定」、「疊層設定」與「繪畫工具」。
2. 底部「主題」可切換清爽青綠、沉靜墨藍、純白、純黑。
3. 「介面」可調整字體與控制項大小；也可拉動視窗邊緣，或按「自動調整視窗大小」。
4. 內容超出視窗時，可用捲軸或滑鼠滾輪查看。

調整格子
1. 「疊層設定」中的「格子寬高」調整色塊大小，「格距」調整格子之間的留白。
2. 可用滑桿調整寬高，或輸入數值後按「套用尺寸」。
3. 遊戲放大倍率改變後，需要重新調整格子大小並對齊。

重新對齊
按 F9 切回對齊模式，用左鍵拖曳疊層，重新對齊遊戲格子。
也可勾選「方向鍵微調疊層」，在繪畫模式微調位置。

截圖校正格線
1. 按 F8 隱藏疊層，讓遊戲格線可見。
2. 切回遊戲，按 Alt＋PrintScreen，複製完整遊戲視窗，不要裁切截圖。
3. 在「疊層設定」按「貼上截圖並校正格子寬高與格距…」，再按「貼上截圖」或 Ctrl＋V。
4. 框選畫布內的格線，每個方向至少包含4條完整格線。
5. 按「量測格線」，確認結果後按「套用量測結果」。
6. 套用後，仍需拖曳疊層對齊遊戲格子。

截圖校正色盤
自動切換畫筆顏色沒有反應或選錯色時，可使用此功能。
1. 展開遊戲右側色盤，確保上方選色條與下方全部色塊完整、清楚可見，沒有被其他視窗遮住。點回遊戲，按 Alt＋PrintScreen，複製完整遊戲視窗，不要只裁切色盤。
2. 在「繪畫工具」展開「色盤位置與校正」，按「貼上截圖並校正色盤位置…」，貼上截圖。
3. 框選色盤上方的彩色長條與下方全部色塊，按「辨識色盤」。
4. 確認預覽中的編號點對準色塊，按「保存色盤校正」。
5. 遊戲解析度或視窗大小改變後，請重新校正色盤。

快速鍵（工具或遊戲視窗在最前方時）
F5：開啟／取消取色模式。
F6：顯示全部顏色。
F7：自動切換畫筆顏色。
F8：顯示／隱藏疊層。
F9：切換對齊／繪畫模式。
Esc：取消等待或執行中的畫筆顏色切換。
部分鍵盤需要搭配 Fn 使用；也可直接按工具上的對應按鈕。

保存與更新
工具會自動保存圖片、畫布、觀看範圍與操作設定，下次開啟時還原。
更新版本時，將舊資料夾中的 config 資料夾複製到新版資料夾，可保留設定。

關閉與移除
按視窗關閉鈕結束工具；刪除解壓縮的資料夾即可移除。

問題處理與診斷紀錄
1. 快捷鍵、同步拖曳或自動選色沒有反應時，可按「功能檢查」，查看遊戲是否以系統管理員身分執行。
   若是，請關閉工具，再對工具執行檔按右鍵，選「以系統管理員身分執行」。
2. 要回報問題時，請記下操作與大約發生時間，再從「功能檢查」按「匯出診斷紀錄…」，將儲存的 ZIP 與問題描述一併提供。
3. 紀錄不會自動傳送，匯出檔案不包含作品或截圖。
4. 回到工具或開啟設定視窗時，疊層可能暫時隱藏；切回遊戲後會恢復顯示。

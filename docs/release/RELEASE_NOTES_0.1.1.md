# Heartopia 繪畫疊層小幫手 0.1.1

在遊戲畫布上顯示參考圖片，協助玩家對照格子、逐色手動繪畫。

## Windows 免安裝版

下載本頁 Assets 中的 `HeartopiaPaintingOverlayHelper-0.1.1-windows-x64.zip`，完整解壓縮後執行 `HeartopiaPaintingOverlayHelper.exe`。適用 Windows 10／11 x64，不需另外安裝 Python。

`Source code (zip)` 與 `Source code (tar.gz)` 是原始碼。一般使用者請下載上述免安裝 ZIP。

## 開始使用

按工具中的「使用教學」，依序載入圖片、設定畫布、連接遊戲並量測格子、對齊疊層，再取色與手動填色。ZIP 附離線教學，也可閱讀[線上圖文教學](https://wingkawa.github.io/heartopia-painting-overlay-helper/)。

## 功能

- 圖片轉為小鎮 125 色、裁切、色彩調整及 PNG 另存。
- 小地圖構圖、自訂畫布與觀看範圍。
- 疊層對齊、單色提示、格線及色盤位置校正。
- 可選用右鍵拖曳同步、方向鍵微調，以及預設關閉的自動選色。
- 保存操作狀態、四種主題、功能檢查及診斷紀錄匯出。

## 使用前須知

本工具為非官方第三方工具，未取得遊戲營運方的使用許可或背書。是否允許使用以適用版本的官方協議、公告及營運方判定為準。自動選色會執行滑鼠操作，預設關閉，需自行閱讀說明並選擇啟用。

拖曳遊戲畫布後疊層可能偏移，請自行確認，用方向鍵微調或 F9 重新對齊。遊戲以系統管理員權限執行時，工具可能也需以相同權限啟動。

遇到問題可從「功能檢查」匯出診斷 ZIP，連同版本、問題描述及發生時間回報；診斷紀錄不會自動上傳。

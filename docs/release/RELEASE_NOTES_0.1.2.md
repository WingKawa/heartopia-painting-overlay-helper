# Heartopia 繪畫疊層小幫手 0.1.2

本次更新教學內容，程式操作方式維持不變。

## 更新內容

- 新增五張實際遊戲截圖，依序說明邊界對齊、同步拖曳、取色與逐色填入。
- 補充方向鍵修正偏移，以及 F8 隱藏疊層查看實際成果的操作。
- 免安裝版附更新後的離線教學，也可閱讀[線上圖文教學](https://wingkawa.github.io/heartopia-painting-overlay-helper/#painting-walkthrough)。

## Windows 免安裝版

下載本頁 Assets 中的 `HeartopiaPaintingOverlayHelper-0.1.2-windows-x64.zip`，完整解壓縮後執行 `HeartopiaPaintingOverlayHelper.exe`。適用 Windows 10／11 x64，不需另外安裝 Python。

`Source code (zip)` 與 `Source code (tar.gz)` 是原始碼，並非免安裝版。舊版本保留於 Releases，供查閱與回退。

## 使用前須知

本工具為非官方第三方工具，是否允許使用以適用版本的官方協議、公告及營運方判定為準。自動選色會執行滑鼠操作，預設關閉，需自行閱讀說明並選擇啟用。

拖曳畫布後疊層可能偏移，請確認並用方向鍵微調，或按 F9 重新對齊。遊戲以系統管理員權限執行時，工具可能也需以相同權限啟動。
